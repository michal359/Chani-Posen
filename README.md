# Chani-Posen
הרפוזיטורי הזה מכיל את הקוד והקבצים של מערכת ניהול קוסמטיקה, שמאפשרת ללקוחות לעקוב אחרי טיפולים, רכישות, ולקבוע תורים. המערכת כוללת אפשרות להעלות תמונות לפני/אחרי טיפול, לקבל המלצות למוצרים, ולנהל את פרטי החשבון. בנוסף, ישנם דשבורד ניהול למנהלים שמספק גישה לפרטי הלקוחות, סטטוס טיפולים, רכישות, והתראות.
